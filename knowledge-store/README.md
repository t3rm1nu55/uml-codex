# Knowledge Store

Comprehensive knowledge base for code reviews, requirements, designs, and insights from analyzed repositories.

## 🎯 Purpose

This knowledge store captures learnings from:
- REGnosys open source components
- FINOS/ISDA CDM
- Camunda workflow engine
- Flowable workflow engine
- Issue analysis across all repositories

## 📁 Structure

- **code-reviews/**: Deep analysis of codebases, components, and reuse decisions
- **issues-analysis/**: Insights extracted from GitHub issues
- **requirements/**: Functional and non-functional requirements identified
- **designs/**: Architectural and design patterns discovered
- **licensing/**: License analysis and code reuse decisions
- **components-inventory/**: Catalog of components we want to adopt/adapt
- **insights/**: Cross-cutting insights and learnings

## 🔄 Versioning

All JSON files include versioning to support iterative learning:
- Each entry tracks `version` and `last_updated`
- Previous insights can be refined as understanding deepens
- Changes are tracked with `change_history`

## 📖 How to Use

1. Start with `components-inventory/` to see what we want to adopt
2. Check `licensing/` to understand reuse constraints
3. Review `code-reviews/` for technical details
4. Explore `issues-analysis/` for real-world insights
5. Reference `requirements/` and `designs/` for patterns
